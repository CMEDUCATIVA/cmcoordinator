# Visor local de geometría Revit

Versión del documento: 0003

Este ejemplo conecta el complemento Cmcoordinator a un visor Three.js que solo escucha en `127.0.0.1:5257`. No utiliza el CDE, genera IFC4 local y no acepta órdenes para modificar Revit desde la web.

## Iniciar el visor

Requisitos: Node.js 24.11 o posterior y npm. Desde esta carpeta:

```powershell
npm.cmd ci
.\iniciar.cmd
```

También puedes ejecutar `npm.cmd start` y abrir http://127.0.0.1:5257. Ctrl+C detiene el servidor. El archivo CMD permite arrancarlo sin cambiar la política de ejecución de PowerShell. La primera instalación necesita descargar la versión fijada de Three.js; las siguientes ejecuciones son locales. Si el puerto está ocupado por un visor ya iniciado, abre su dirección; si lo ocupa otra aplicación, detén esa aplicación antes de iniciar este ejemplo.

## Compilar y cargar el complemento

Desde la raíz `Cmcoordinator`:

```powershell
dotnet build src/OpenProject.Revit/OpenProject.Revit.csproj -c Debug-2026 -p:Platform=x64 -p:EnableAppDataDeployment=false
```

Para 2027 usa `Debug-2027`. La compilación no instala el complemento. Revit debe cargar esa nueva DLL mediante el despliegue que usas para Cmcoordinator; evita copias duplicadas y consulta `GUIA.md` del repositorio. Si Revit ya estaba abierto con otra versión, hay que cerrarlo y actualizar su instalación antes de reiniciar. No se reemplazan DLL cargadas automáticamente.

## Probar el cubo

1. Abre un proyecto y una vista 3D que muestre el origen interno.
2. En `Cmcoordinator → Visor local`, pulsa **Iniciar visor local**. La vista 3D activa queda como vista de origen hasta detener y volver a iniciar.
3. Crea o modifica un elemento del modelo; el visor recibirá la geometría real y sus propiedades. El comando de cubo demo se retiró del menú.
4. El cubo debe aparecer con su geometría real. Si hay más geometría, usa **Encuadrar modelo** o F.
5. Mueve o elimina el cubo en Revit y comprueba el visor. Para probar cambios de forma/dimensiones, edita un elemento nativo como un muro o una familia; el DirectShape de prueba no tiene parámetros de ancho/alto.
6. Selecciona una pieza en la web para ver su identificador y propiedades. La selección web no cambia la selección en Revit.
7. Pulsa **Detener visor local** para dejar de publicar. La última escena permanece en memoria del servidor hasta otra sesión o hasta detenerlo.

El tooltip del botón indica estado de extracción/envío, desconexión o pausa por documento distinto. El estado web distingue conexión al servidor y última actualización recibida; no garantiza que Revit siga abierto.

## Arquitectura y recuperación

- `src/OpenProject.Revit/LiveSync/LiveGeometryContext.cs`: teselación Revit y transformaciones de instancias/vínculos, coordenadas en metros con Z vertical.
- `LiveMetadata.cs`: propiedades de instancia y de tipo.
- `LocalLiveSync.cs`: sesión, vista fija, acumulación de cambios y extracción en Idling, con agrupación de 650 ms.
- `LiveContracts.cs`: base/delta con identidad y secuencia.
- `LivePublisher.cs` y `LocalSyncTransport.cs`: trabajo de red separado de Revit API; solo se confirma una base tras respuesta HTTP. Se conserva el snapshot más reciente y se vuelve a enviar completo ante pérdida de estado. Una comprobación cada 2,5 s detecta reinicio del servidor sin nuevas ediciones.
- `lib/`: validación, estado y servidor HTTP/SSE. Duplicados idénticos se confirman sin repetirlos. Secuencias/base incorrectas reciben 409; una sesión ya reemplazada recibe 403.
- `public/`: estado, renderizador e interfaz separados. SSE entrega una base al entrar/reconectar y deltas posteriores. El renderizador libera geometrías/materiales reemplazados y rebasa coordenadas antes de convertir a float32.

La cola acumula cambios mientras la red está caída sin repetir teselación de elementos sin cambios. Si una respuesta se pierde o el servidor reinicia, se reconstruye el estado mediante una base completa. El ejemplo admite un único productor activo; iniciar otro reemplaza la sesión anterior.

## Límites de esta fase

- Se publica la geometría visible en la vista elegida; elementos ocultos no se incluyen. Solo se publican operaciones confirmadas, no la previsualización de un arrastre sin confirmar.
- Materiales, tipos, vistas y vínculos disparan una base completa para evitar dependencias obsoletas. Los demás cambios se filtran por elemento. Una vista puede seguir teniendo un coste de recorrido aunque se limite la teselación.
- Incluye mallas poligonales, color y transparencia; no incluye texturas, luces, curvas, anotaciones ni RPC sin polymesh.
- Máximo 32 MB por petición, 20.000 elementos y 750.000 vértices por escena. Usa una vista pequeña para el primer ensayo. No es una promesa de rendimiento con modelos grandes.
- Solo loopback; sin persistencia ni autenticación de usuarios. Se rechazan otros Host/Origin y no se habilita CORS externo. No exponerlo en red ni reutilizar este servidor como CDE.
- La vinculación de modelos anidados y cambios de coordenadas deben validarse en modelos reales antes de producción. La compilación y pruebas del protocolo no verifican por sí solas el render de Revit.

## Verificación

```powershell

```

Las pruebas de servidor usan puertos efímeros, mallas de cubo con doce triángulos, secuencias, recuperación, borrados, límites y acceso local. Las pruebas C# están en `test/OpenProject.Tests/LiveSync`. No sustituyen la comprobación visual con Revit.

## Cmcoordinator: datos BIM y generación IFC

1. Abre una vista3D y pulsa Centro de sincronización en la pestaña Cmcoordinator. La captura nueva envía esquema BIM2, parámetros de instancia/tipo con IDs y valores/unidades, niveles, familias, materiales/capas, fases y anfitrión.
2. En el visor local, selecciona un elemento. Usa las secciones y búsqueda de propiedades para consultar los datos; los parámetros sin valor se identifican como tales.
3. Pulsa GenerarIFC cuando esté presentada la revisión. El servidor congela esa revisión, genera y valida IFC4 fuera de Revit y ofrece DescargarIFC e Informe de cobertura. Cambios posteriores no alteran el archivo ya generado.
4. El IFC contiene el alcance de la vista3D sincronizada, geometría triangulada y propiedades capturadas; el informe declara proxies, relaciones fuera de alcance y unidades no normalizadas. No equivale al modelo completo RVT o a una exportación IFC nativa certificada.

Runtime IFC aislado: Python3.14 y ifcopenshell0.9.0.post1. Preparar con tools/setup-ifc-runtime.cmd; no cambia Python global. Ruta del runtime: %LOCALAPPDATA%/Cmcoordinator/Runtime. Para un intérprete equivalente configurado puede usarse COORDINATOR_PYTHON. Datos persistentes y archivos versionados: %LOCALAPPDATA%/Cmcoordinator/LiveSync. El paquete de código es local; no envía datos al CDE. Publicaciones IFC guardadas en exports/<id> conservan snapshot, IFC, reporte y estado. No borrar esta carpeta para resolver problemas de conexión.

La migración de esta instalación conserva cola/configuración anteriores y mantiene un solo manifiesto activo por versión de Revit. Si cambiaDLL, cerrar Revit antes de instalar y abrirlo después. Recargar navegador con Ctrl+F5 para actualizar módulos. La carpeta fuente del complemento es D:/Cmcoordinator.
